🧠 AI Vision Extraction App

   Automatically extract objects from images using DeepLabV3+ segmentation with PyTorch. This interactive web app allows users to upload any image, isolate the main object, and download it with a transparent or black background.

🚀 Features

   Automatic Object Extraction – Uses a pre-trained DeepLabV3  model for accurate segmentation.

   Iteractive Web App – Built with Streamlit, includes live preview and download.

   Animated Gradient Background – Clean, modern UI for a visually appealing experience.

   High Accuracy – Test Time Augmentation (TTA) applied automatically for improved segmentation.

   Cross-Platform – Works on both CPU and GPU; GPU accelerates inference significantly.

   Supports Multiple Formats – Upload JPG, JPEG, or PNG images.
