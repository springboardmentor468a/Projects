# VisionExtract: Automatic Subject Isolation using Image Segmentation

**VisionExtract** is a deep learning-powered web application that automatically extracts the main subject from an image, removing the background.  
This project leverages a **U-Net model** with a **pre-trained ResNet34 encoder** to perform high-accuracy image segmentation.
